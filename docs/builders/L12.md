## Build
1. **The compiler as WebAssembly** (ore repo): `crates/ore-wasmc` builds the compiler (parse, types, lower, codegen, no wasmtime) to `wasm32-unknown-unknown`. It exports `compile(src) -> {wasm} | {diagnostics}` and `check(src)`, so any JavaScript host can compile Ore with no install. `packages/host` gains `compile(src)`.
2. **Edge Function `ore-run`** (Build `supabase/functions/ore-run`):
   - Deno, vendoring `packages/host` and the compiler `.wasm` into `_shared/ore/` with a version header.
   - Requires a signed-in Build user (the same JWT check as the other functions).
   - Takes `{src, entry?, stdin?, fuel?}`, grants nothing (P10; no fs or net in v1), and caps memory at 128 MB and fuel at 10^8.
   - Returns the host's JSON.
   - Deploy it with `npx supabase functions deploy ore-run --use-api` (memory: edge functions deploy that way); shipping backend with code is part of done.
3. **BPR** (Build `planreader/src-tauri`): add `ore-host` as a git dependency pinned to a tag, plus a Tauri command `ore_run` and an `apr_ore_run` tool in `planreader/bridge-mcp`, so agents working in BPR run Ore locally with grants the person approves (fs confined to the job folder they pick).
