# L7: WebAssembly backend and runtime (two builders in parallel)

Both are cut from `main` after L6 merged. Both build against `docs/ABI.md` alone. If ABI.md is wrong or missing something, change it in a small commit, say so in your report, and tell the coordinator. Don't work around it silently.

## L7a: runtime (`l7a-runtime`, crate `crates/ore-rt`)
- Rust, `#![no_std]` with its own allocator, compiled to `wasm32-unknown-unknown`. Run `rustup target add wasm32-unknown-unknown` once.
- Implements every runtime function in ABI.md:
  - allocator (size classes plus a free list);
  - UTF-8 strings with slices; `words`, `split`, `lines`, `trim`, `lower`, `upper`, `replace`;
  - number parsing and printing (Python `repr` for floats, matching the interpreter byte for byte);
  - arrays with in-place updates when the count is 1, and sorting (stable);
  - insertion-ordered open-addressing hash maps;
  - JSON parse to the typed shapes L4 elaborates, and `tojson`;
  - `days`, `date`, `weekday`; structural equality, ordering and hashing.
- Imports nothing from the host. Host effects are imported by the program module (L7b), so a module's imports show exactly which grants it needs.
- `scripts/build_rt.py` builds it (through `scripts/cargo.py`) to `crates/ore-rt/ore-rt.wasm`. Check that file in, so the compiler doesn't need the wasm target to build programs.
- **Gate:** a small Rust test harness on wasmtime calls each runtime function on the edge cases in `data/library-tests.ore` and compares with the interpreter. Plus one `cargo check`.

## L7b: code generator (`l7b-codegen`, crate `crates/ore-wasm`)
- Low IR to WebAssembly with `wasm-encoder`.
- **One output module:** merge `ore-rt.wasm` into the program with `wasm-encoder`'s reencoding (index remapping), so runtime calls are direct calls.
  - Inline the hot paths (count increment and decrement, field loads, Int and Float arithmetic, tag switches) instead of calling the runtime.
- **Host imports** only for effects the program uses (from L4's rows), named as in ABI.md.
- **Fuel:** a global decremented at every loop head and function entry. At zero, set a reason global and trap; the host maps that to C002.
- Exports: `main`, each test thunk (so `ore check` can run tests compiled), and the memory.
- **CLI:** `ore build FILE -o out.wasm`.
- **Gate:** until L8 lands a host, run each corpus program in wasmtime from a small test harness crate (or in Node with a 30-line loader). Its output must equal L3's interpreter line for line on the whole corpus. A module that uses no effects must import nothing. Plus one `cargo check`.
