# L8: Hosts and native code

Branch `l8-hosts`, cut from `main` after L7a and L7b merged.

## Build
1. **`crates/ore-host` (Rust, wasmtime):**
   - Compile or load a module.
   - Refuse before instantiation if it imports anything outside the granted effects (C001, naming the missing grant).
   - Provide only the granted imports. stdin, stdout and the file root are configurable; `fs` is confined to one directory the caller names.
   - Map the fuel trap to C002, a stack overflow to C003, and the memory limit to C004 (add C003/C004 to DIAGNOSTICS.md).
   - Default memory cap 256 MB and fuel 10^9 steps, both overridable.
   - Public API: `run(module, Grants, Limits, Io) -> Outcome`, which BPR embeds later (L12).
2. **CLI:**
   - `ore run FILE` compiles and runs through `ore-host` by default; `--interp` keeps the interpreter.
   - `ore build FILE --target wasm|native`, where native is wasmtime's ahead-of-time `Engine::precompile_module` to `.cwasm`, loaded with `Module::deserialize`.
   - `ore check` runs tests compiled when the program types, and falls back to the interpreter only for files that don't compile yet, saying so in the summary line.
3. **`packages/host` (JavaScript ES module):**
   - One file, no dependencies, for Node 18+, Deno (Supabase Edge Functions) and browsers.
   - `run(bytes, {grants, fuel, memoryMB, stdin, files})` gives `{stdout, error}`, with the same refusal and trap codes as the Rust host.
   - Use the same import names as ABI.md.
4. **Escape suite** (`crates/ore-host/tests/escape/`), 30 programs or modules:
   - net, fs, io, time and rand without grants;
   - fs paths outside the root (`..`, absolute paths, UNC on Windows);
   - endless loops, deep recursion, memory bombs, huge strings, a 10^9-element `range`;
   - a module hand-edited to import a host function it has no grant for, or a nonexistent one.
   - Every one must be refused or stopped with the right code, in both hosts.

## Gate (run once, at the end)
- The corpus gives identical output under `ore run` (wasmtime), `ore run` on a `.cwasm`, and Node with `packages/host`.
- G6: 30 of 30 escapes blocked in the Rust host and in Node.
- One `python scripts/cargo.py check --workspace`. wasmtime is heavy, so build it once and reuse the target folder.
