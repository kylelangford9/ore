# L9: Library

Branch `l9-library`, cut from `main` after L3 merged. Runs alongside L4 (types) and L5 (store). You own `data/library.json`, `docs/LIBRARY.md` and the verbs' Rust code in `ore-core`, plus the matching spike code.

## Build
1. **One entry per verb in `data/library.json`:**
   - name, arity, type (a string in card notation, for example `(a -> b) -> [a] -> [b]`), effects, and the inputs that make it `fail`;
   - `prim: true` when L7 should implement it in the runtime rather than in Ore.
   - L4 reads the types from here. Add the types even before L4 merges.
2. **Exact semantics in `docs/LIBRARY.md`:** one line each, nothing for human reading beyond what a model needs. Settle every edge case once:
   - empty lists, negative `take` and `drop`, `@-1`, ties in `sortby`, `minby` and `maxby` (first wins);
   - `split ""`, `words` on Unicode whitespace, `round` half away from zero;
   - `int " 12 "`, `int "1e3"` (fails), `float "nan"` (fails), `str` of floats (Python `repr` rules);
   - map key order after `put` (an existing key keeps its place) and `del`, `++` on maps (right side wins, left order kept);
   - `group` and `count` order (first occurrence), `json` numbers (integers stay Int);
   - `tojson` of records (fields in label order), `days`, `date` and `weekday` (proleptic Gregorian).
3. **Examples that double as tests:** `data/library-tests.ore`, with 3–6 `test` lines per verb covering those edge cases. Rust (`ore check`) and the spike must both pass all of them; fix whichever is wrong.
4. **Card sync:** the card's library lines must list exactly the verbs in `library.json`. Add a check script, `spike/cardsync.py`, that fails on any difference. The card stays ≤ 1,500 o200k tokens.
5. **Bake-off feedback:** apply L1's recommended aliases (`data/aliases.json`) and verbs that clear the bar: models reached for it in at least 5 tasks, and it costs ≤ 15 card tokens. Leave the rest in the report.

## Gate (run once, at the end)
- `data/library-tests.ore` passes in `ore check` and in the spike.
- `cardsync.py` passes.
- One `python scripts/cargo.py check --workspace`.
