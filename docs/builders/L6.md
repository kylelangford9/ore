# L6: Lowering (Rust)

Branch `l6-lower`, cut from `main` after L4, L5 and L9 merged. Crate `crates/ore-lower`. You also write `docs/ABI.md`: L7a builds the runtime and L7b the code generator from it, in parallel, right after you.

## Build
1. **Monomorphize** typed Core (from L4): one copy per concrete type instance, keyed by `(definition hash, type)` so the store's hashes key the compile cache. Numeric widening is resolved here. No polymorphic code reaches the backend.
2. **Closure conversion:** lambdas become top-level functions plus an environment record. Calls to known functions become direct calls, and partial application allocates once.
3. **ANF:** every intermediate gets a name, and evaluation order is explicit (left to right, as in the interpreter).
4. **Match compilation:** decision trees (Maranget-style) over constructor tags, literals, list length and prefix (`[p, ..t]`), tuple and record fields. Guards fall through. A non-exhaustive match ends in `fail "match: no arm for <value>"`, worded like the interpreter's.
5. **Low IR** (`ore-lower/src/low.rs`): explicit allocations, field loads and stores, tag switches, direct and indirect calls, runtime calls by name (`rt_alloc`, `rt_str_concat`, `rt_map_put`, …), `dup`/`drop`, and a result flag for `fail`.
6. **Perceus reference counting:**
   - insert `dup` and `drop` with borrow inference for parameters that are only read;
   - drop specialization;
   - reuse: a constructor or array freed in a branch is reused for an allocation of the same size in that branch.
   - Arrays update in place when the count is 1. `[h, ..t]` binds `t` as a slice (base, offset, length) sharing the base's count.
7. **Control:**
   - Self tail calls become loops; other tail calls stay calls (no tail-call feature needed).
   - `fail` becomes result passing: every function that can fail (from L4's effect rows) returns a flag that callers check.
   - `catch` is a branch on the flag.
8. **`docs/ABI.md`:**
   - Object layouts: header (count i32, tag or kind, size), Str (UTF-8, length, plus a slice form), arrays and slices, insertion-ordered maps, records (fields sorted by label), constructors, closures, boxed floats inside collections.
   - Every runtime function with its signature, and the fuel counter global.
   - Host imports per effect (`ore:io/print`, `ore:io/stdin`, `ore:fs/read`, `ore:fs/write`, `ore:net/http`, `ore:time/now`, `ore:rand/next`).
   - How `main` and test entry points are exported.
   - L7a and L7b each build against this file alone.
9. **Low IR interpreter** with a leak checker (counts every allocation and free). It is the debug runtime.

## Gate (run once, at the end)
- Differential: on the full corpus (examples, task references, the bake-off's passing programs), the Low IR interpreter's `check` and `run` output equals L3's interpreter, line for line.
- Leak checker: zero live objects at exit on every corpus program.
- One `python scripts/cargo.py check --workspace`.
