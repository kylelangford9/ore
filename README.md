# Ore

A programming language written by models and run by machines. Nobody needs to read it.

- `spike/SPEC-CARD.txt` is the whole language, as a model sees it.
- `spike/ore.py` is the reference implementation. Every later stage is checked against it.
- `docs/PLAN.md` holds the approved plan, the picks, the gates and the build order.
- Plan page: https://claude.ai/artifact/45xKKEhAGsP5RCojS6dh5n

Build on Kyle's PC with `python scripts/cargo.py <cargo args>`. It loads the portable MSVC toolchain and writes build output to `D:\Build Artifacts\ore\target`.
